# Security Policy
The use of AI to create code is strictly forbidden in this project. Using AI to for example point out all merge conflicts is a valid use of AI. Only making your life easier, not doing your job for you.

## Supported Versions

This project is currently in beta, so it is not officially supported, nor does it work.

| Version | Supported          |
| ------- | ------------------ |
| beta    | :white_check_mark: |

## Reporting a Vulnerability
If there are any issues with security, leave a message on the Discord or in the Issues tab
